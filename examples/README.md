# Examples

| Path | What it is |
|---|---|
| `sample_report.md` | Markdown report produced from a made-up transcript. It is not a real meeting or a quality benchmark. |
| `sample_meeting.json` | Synthetic `meeting.json` example showing the output schema. |
| `search_questions.example.json` | Template for real Recall@k evaluation; replace the placeholder IDs and relevance labels with your own dataset annotations. |
| `synthetic_evaluation/` | Hand-written toy transcript, action-item lists, and simulated search rankings used by `scripts/run_synthetic_evaluation.py`. All reported values are illustrative metric calculations only. |

No raw audio or private meeting recordings are included in this repository.
